usage: label_journals.py [-h] [--input INPUT] [--output OUTPUT]
                         [--batch-size BATCH_SIZE] [--max-entries MAX_ENTRIES]

Label journal JSONL entries with LLM subscores.

options:
  -h, --help            show this help message and exit
  --input INPUT         Input JSONL path containing journal_text.
  --output OUTPUT       Output JSONL path with labels added.
  --batch-size BATCH_SIZE
                        Entries processed per progress interval.
  --max-entries MAX_ENTRIES
                        Optional cap on entries labeled in this run.

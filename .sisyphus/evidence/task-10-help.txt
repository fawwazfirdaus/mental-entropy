usage: train_gam.py [-h] --labeled-data LABELED_DATA [--output-dir OUTPUT_DIR]
                    [--k-folds K_FOLDS]

Train CE and NE pyGAM regressors from labeled JSONL.

options:
  -h, --help            show this help message and exit
  --labeled-data LABELED_DATA
                        Path to labeled JSONL input.
  --output-dir OUTPUT_DIR
                        Directory where gam_ce.joblib, gam_ne.joblib, and
                        metadata JSON are written.
  --k-folds K_FOLDS     Requested number of CV folds (default: 5).

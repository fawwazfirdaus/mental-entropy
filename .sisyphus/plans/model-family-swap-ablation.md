# Model Family Swap Ablation Plan

## TL;DR

> **Quick Summary**: Run a controlled ablation to test whether swapping model families improves subscore quality: XGBoost for CE/NE and GAM for SE/CLE versus the current baseline mapping.
>
> **Deliverables**:
> - Reproducible experiment protocol and artifact layout
> - Baseline + swap training runs with fixed data splits
> - Unified val/test evaluation report (MAE + Spearman per subscore)
> - Decision report (keep baseline, full swap, or mixed per-subscore winner)
>
> **Estimated Effort**: Medium
> **Parallel Execution**: YES (5-8 tasks per wave)
> **Critical Path**: T1 -> T2 -> T3 -> T9 -> T12 -> T13

---

## Context

### Original Request
User requested an experiment to test whether swapping model families yields better performance:
- CE/NE with XGBoost (instead of GAM)
- SE/CLE with GAM (instead of XGBoost)

### Interview Summary
- Baseline is already trained and functional.
- Anchor-based LLM labels stay unchanged.
- Current priority is optimization and retraining quality, not architecture redesign.
- Heuristic alignment is informational only; main decision quality is from human-only val/test behavior.

### Metis Review
Key guardrails from Metis:
- Keep baseline as control under the same protocol window.
- Reuse the same train/val/test files exactly (no resplitting).
- Use labels-only target source during training (avoid heuristic fallback contamination).
- Use one shared evaluator for MAE and Spearman across all variants.
- Pre-register decision rule before reading test outcomes.

---

## Work Objectives

### Core Objective
Determine whether swapped model-family assignments improve subscore quality over baseline under a fair, reproducible evaluation protocol.

### Concrete Deliverables
- Experiment protocol notes and command manifest
- Baseline artifacts in isolated experiment directory
- Swap artifacts in isolated experiment directory
- Unified val and test reports for both variants
- Final recommendation report with per-subscore winner and global rollout advice

### Definition of Done
- [x] Baseline and swap variants are both trained from the same train split
- [x] Unified evaluator reports MAE + Spearman for CE/SE/NE/CLE on val and test
- [x] Decision report applies pre-registered rule without manual interpretation
- [x] Full test suite still passes after experiment tooling updates

### Must Have
- Fixed train/val/test files reused exactly
- Comparable training/eval conditions between families
- Deterministic run config and output artifact naming
- Clear decision rule with explicit tie-break behavior

### Must NOT Have (Guardrails)
- Must NOT change feature extraction modules
- Must NOT change MES combiner weights or formula
- Must NOT tune on test set or select winners using test iteration loops
- Must NOT use heuristic fallback labels for experiment targets
- Must NOT mix experiment artifacts with production default model paths

```

├── T2: Create artifact/output directory contract

├── T4: Add unified evaluator skeleton

├── T6: Enable XGB path for CE/NE

├── T10: Run baseline training/eval bundle

├── T13: Apply pre-registered decision rule and write recommendation report

├── F1: Plan compliance audit
├── F2: Code quality and test audit
├── F3: End-to-end scenario replay
```
